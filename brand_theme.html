Brand Theme & Design Guidelines

1. Brand Logo

The official brand logo must be used consistently across all marketing materials, site headers, and promotional content.

2. Typography

The primary font family used throughout the application provides a clean, modern, and readable experience. It is designed to be accessible and professional.

Primary Font: Poppins (Regular - 400)

Headings: Poppins (Semi-Bold - 600)

Emphasis: Poppins (Bold - 700)

4. Glassmorphic UI Elements & Responsiveness

The entire application is built with a mobile-first, responsive design that fluidly adapts to any screen size (scaling smoothly from 1700px down to 400px for mobile devices). Additionally, a premium glassmorphism aesthetic is applied across elevated UI elements. This is achieved using semi-transparent white backgrounds (rgba(255, 255, 255, 0.65)) coupled with soft translucent borders, creating a vibrant frosted-glass effect.

Card Layout Example

Features an 8px border radius, 2px solid border, and subtle drop shadow. Used for products and informative content.
